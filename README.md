A one-line joke entry for make.fun's "Monday Morning Punchlines" competition. The tiny Node program in `main.ts` writes a single Monday-morning punchline (at most 200 characters, guarded in code) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The joke skips the tired "I hate Mondays" and coffee complaints: Monday morning delivers a brand-new person — who tragically inherits the same job, the same boss, and a 9 a.m. standup.

## Run it

```sh
node main.ts
```
